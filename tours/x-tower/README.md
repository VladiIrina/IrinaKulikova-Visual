# ЖК «X-TOWER» — 3D-тур

Город: Грозный
Год: 2026

Интерактивный локальный 360° просмотрщик на основе предоставленных панорам пользователя.

Навигация:
- список помещений слева;
- кнопки предыдущая/следующая панорама;
- план квартиры;
- сброс направления;
- полноэкранный режим;
- управление мышью/пальцем и колесом.
