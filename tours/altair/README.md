# 360° тур из панорам

В проект включены 6 панорам и план квартиры.

## Как работает
- мышь / палец — вращение 360°
- колесо мыши / жест масштабирования — приближение
- меню «Помещения» — переход между панорамами
- «План» — показывает план квартиры
- «Во весь экран» — полноэкранный режим

## Важно
Для работы локально через компьютер браузеру нужен HTTP-сервер; двойной клик по index.html может блокировать локальные ресурсы.
Для публикации в интернете загрузите всю папку на обычный HTTPS-хостинг.

- Гостиная · окно
- Коридор
