# Администрирование портфолио

После публикации сайта через GitHub + Netlify админка доступна по адресу `/admin/`.

## Добавление нового проекта
1. Откройте `/admin/`.
2. Выберите «Проекты портфолио» → «Новый проект».
3. Выберите одну категорию:
   - Интерьеры
   - Экстерьеры
   - Модели мебели
   - Анимация
   - 3D-туры
4. Добавьте обложку и галерею.
5. Для анимации загрузите MP4 и укажите его в галерее/обложке.
6. Для 3D-тура укажите ссылку на тур.
7. Сохраните проект.

Категория является единственной: проект отображается только в выбранной категории.
